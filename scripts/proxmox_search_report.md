## 3. RAIDカード・ITモード / オンボードSATA

- **富士通 CP400i (PRAID)**: q1222082071, m1220880274 → RAID機能付き。ITモード（パススルー）ではない。オンボードSATAは機種により利用可。
- **Dell PERC H730P / P730P**: j1213452155, s1209550496 → RAIDコントローラ。ITモード化は一般的でない。HBAが必要なら別途「LSI 9211-8i IT」「LSI 9300-8i IT」等を検索済み。
- **HPE P208i-p / P408i-p**: 検索結果内のML30 Gen10等 → RAID。ITモード化は非公式対応。オンボードSATAの有無は説明文・マニュアル確認推奨。

**結論**: 純正RAID搭載機はそのままではITモードにならないため、ZFS/Proxmoxでパススルーしたい場合は **HBA（LSI 9211-8i/9300-8i IT mode）を別途挿す構成**が無難。パーツ検索でヒットあり。

## 6. 再利用用・API呼び出し例

- **検索**: `POST http://localhost:8080/yahoo_auction.v1.YahooAuctionService/SearchAuctions`  
  `{"query": "HPE ML30 Gen10", "page": 0}`
- **商品詳細**: `POST http://localhost:8080/yahoo_auction.v1.YahooAuctionService/GetAuction`  
  `{"auctionId": "j1213452155"}`

生データは `scripts/proxmox_search_result.json` に保存済みです。
